# Settings control coverage

Figma geometry, components, typography and both palettes are implemented in the shared Settings shell. Controls use the labels and ordered options in `src/shared/enums.ts`; invalid drafts stay visible while the main-owned last valid config remains active. `config:patch` validates merged sections in main and changes only supplied fields, preserving independently updated native positions. Secrets have no read-back IPC.

Settings Reset uses a native confirmation and resets only the panel's sections; cancelling preserves drafts. Model, Voice and Voice Input resets explicitly clear their own keys. Other invalid drafts survive a reset of a different panel. Ctrl+F and the specified Ctrl+1–8 order are implemented; unfinished panels remain visibly unavailable until their phases are accepted. Closing Settings keeps the companion running.

User scope update (October 8, 2026): General control 17, Capture screen region and attach, is removed from the current shortcut UI. The legacy `hotkeys.region` schema field remains for configuration compatibility but is not an active shortcut or current-release requirement. Region capture is low-priority future work.

Mouth animation/lip syncing are also low-priority future work by explicit user instruction. Voice mouth-sync controls and Test Voice's mouth preview are excluded from this release. Sprites identifies its retained mouth controls as asset preparation; the preview tone is not speech lip syncing.

Acceptance evidence: Windows Electron Settings test exercises live scale 50/100/250%, invalid URL/font retention, fuzzy hotkey search, conditional fields, prompt replacement, stop-tag bounds, actual Windows `safeStorage` encryption, explicit verification versus refresh, changed-key invalidation, cancel/confirm resets, both palettes and the single-window rule. Storage unit tests cover provider isolation, corrupted-key preservation, optional history, restart restore and failed writes. Real local-model acceptance includes Test Connection and model discovery; its isolated server is stopped afterward.
